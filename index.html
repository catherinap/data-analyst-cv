01
Currently in active development

Analytical COT Intelligence Workspace

A full-stack analytical platform for Commitments of Traders research, cross-asset positioning, and macro regime interpretation. A scheduled Python worker pulls weekly CFTC data into PostgreSQL; a FastAPI backend serves cached analytics to a React dashboard spanning correlation, seasonality, signals, historical data, and a custom macro-sentiment panel. Fully containerized with Docker, bilingual (EN / UK), developed with AI assistance across the full build.

  • React + Vite
  • FastAPI
  • Python
  • PostgreSQL
  • Docker
  • COT Analytics
  • OpenAI API
  • AI-assisted development
02
Positioning across markets

COT Positioning Dashboard

An Excel-based analytical system for tracking and interpreting Commitments of Traders data across FX, commodity, and crypto markets. The framework organizes raw CFTC positioning data, compares participant groups - including Leveraged Money, Asset Managers, and Dealers - and generates structured weekly signals to support market bias decisions.

  • Excel
  • CFTC Data
  • Positioning Analysis
  • COT Index
  • Multi-market
  • Weekly Signals
03
Indicator concepts in TradingView

TradingView COT Indicator

A custom Pine Script v6 indicator built in TradingView to visualize COT positioning data directly on price charts. The indicator calculates COT Index, net positioning changes, divergence signals, and a composite weekly bias - translating raw CFTC data into actionable chart-based context.

  • Pine Script v6
  • Divergence Signals
  • Composite Bias
  • Market bias
  • TradingView
